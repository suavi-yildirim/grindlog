Grindlog

A job application tracker that makes applying feel like progress. You earn XP for the work you put in, not for the answers you get back.

Open the tracker

How it works

  • Log each application, then log the steps you take: applied, tailored, followed up, interview.
  • Each step earns XP. Rejections earn nothing and cost nothing.
  • A weekly goal bar tracks your effort, and levels rise as your XP grows.
  • There are no streaks, so a missed day never takes anything away.

Private by default

The tracker runs in your browser and keeps your data there. Nothing is uploaded and no account is needed. You can export a JSON backup whenever you like.

The code is public. View the code on GitHub.
